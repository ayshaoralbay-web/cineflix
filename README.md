Movie website with user registration, login and user management.

## Stack
Node.js, PostgreSQL, HTML, CSS, JavaScript

## Features
- Register and log in
- View, edit and delete users
- Data stored in PostgreSQL (migrated from data.json)

## Run locally
1. npm install
2. Create a PostgreSQL database and run schema.sql
3. Copy .env.example to .env and fill in the values
4. node backend/server.js
5. Open the frontend with a local static server
